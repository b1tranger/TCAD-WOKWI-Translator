# Implementation Plan - Built-in Examples Gallery

Add a built-in **Examples Gallery** modal directly into the application header, featuring 9 diverse, pre-configured circuits across Digital Logic, Dual Microcontrollers, Sensors, Displays, and Actuators. Users can browse, search by category, and instantly load circuits into the interactive workspace for visual simulation and Wokwi export.

## User Review Required

> [!IMPORTANT]
> The Examples Gallery will provide instant, zero-latency 1-click loading of complete circuit topologies without relying on external network requests or URL parsing. Each example includes full native schematics, exact wire routes, component models, and valid Wokwi `diagram.json` compilation.

### Proposed Circuit Examples Catalog (9 Pre-Loaded Designs):
1. **Under-Voltage Protection System** (*Sensors & Displays*): Arduino Uno R3, 9V Battery, 16x2 I2C LCD, Piezo Buzzer, Reset Button, Potentiometer, and AREF jumper.
2. **I2C Master-Slave Communication** (*Microcontrollers*): Dual Arduino Uno boards with 4-wire I2C bus harness, Potentiometer input on Master A0, and PWM dimmable LED on Slave Pin 9.
3. **Dual MCU Direct Serial Link** (*Microcontrollers*): 2x Arduino Uno with pushbutton input, pull-down resistor, LED indicator, and bench Digital Multimeter.
4. **Lab 04 Boolean Function $F = A + B'$** (*Digital Logic*): 74HC32 OR gate, 74HC04 NOT gate, 4-position DIP switch, and DC bench power supply.
5. **DLD 7408 AND Gate** (*Digital Logic*): 7408 Quad 2-Input AND gate with dual tactile pushbuttons, pull-down resistors, and output LED.
6. **Ultrasonic Distance Radar** (*Sensors & Displays*): Arduino Uno with HC-SR04 Ultrasonic Distance Sensor and RGB status LED indicator.
7. **Temperature-Controlled Fan** (*Actuators*): Arduino Uno with TMP36 analog temperature sensor, NPN transistor, and DC fan/motor.
8. **Servo Motor Angle Controller** (*Actuators*): Arduino Uno with SG90 Micro Servo (0°–180°) controlled by rotary analog potentiometer.
9. **Pedestrian Traffic Light Intersection** (*Microcontrollers*): Timed Red/Yellow/Green traffic lights with pedestrian crossing pushbutton.
