# Implementation Plan: Wokwi Modal Fix, Mobile Floating Action Menu & Touch Dragging

Fix the `UI.openModal is not a function` error, redesign the mobile layout to replace top-bar clutter with a bottom expanding floating action menu (FAB), and resolve the mobile "tap-hold and drag" touch interaction on the canvas.

## User Review Required

> [!IMPORTANT]
> 1. **Top Bar on Mobile ($\le 768\text{px}$)**: Will now be completely clean and spacious, containing only the Component Catalog toggle, Brand title & badge, and Inspector drawer toggle.
> 2. **Bottom Floating Action Menu (FAB)**: A sleek bottom-right floating button will expand into a frosted-glass action sheet with easy-to-tap tiles for all 7 functional actions (Import TCAD, Wokwi, HTML, JSON, Changelog, Docs, GitHub).
> 3. **Mobile Touch & Drag Gestures**: Canvas and components will use `touch-action: none`, `setPointerCapture`, and touch event handling to ensure tap-hold-and-drag on mobile devices feels as natural and responsive as desktop click-and-drag, with pinch-to-zoom support for two fingers.

---

## Proposed Changes

### 1. Core UI Library (`js/ui.js`)
- **Add Modal Helper Methods**:
  - Implement `UI.openModal(modalIdOrEl)`: finds target modal, adds `.open` class, and triggers display animation.
  - Implement `UI.closeModal(modalIdOrEl)`: removes `.open` class.
- **Implement Mobile Floating Action Menu**:
  - Add `initMobileFabMenu()` in `UI.init()`.
  - Wire toggle on the floating action button to open/close the bottom expanding sheet.
  - Wire backdrop tap, close button tap, and `Escape` key to dismiss.
  - Action delegation: tapping any item in the sheet dispatches the click to the corresponding functional handler (`#btn-export-wokwi`, `#btn-import-tcad`, etc.) and automatically closes the floating menu.

### 2. Header & Mobile Menu Layout (`index.html`)
- **Add Mobile FAB Structure**:
  - Add `#mobile-fab-container` containing backdrop, expanding sheet card with header and 7 action tiles (Import TCAD, Wokwi, HTML, JSON, Changelog, Docs, GitHub), and the floating action trigger button.
- **Update Version Badge**:
  - Update badge to `v0.1.10` and asset query strings to `?v=0.1.10`.

### 3. Touch Dragging & Panning Interactions (`js/renderer.js`)
- **Pointer & Touch Drag Handling**:
  - Refactor interaction handlers to leverage Pointer Events with fallback to Touch Events.
  - Call `e.preventDefault()` on `touchstart` / `pointerdown` for components and canvas to prevent mobile browsers from triggering native page scrolling or text selection.
  - Use `svg.setPointerCapture(e.pointerId)` on drag initiation so dragging remains locked to the pointer stream even across rapid swipes.
  - Handle `touchcancel` and `pointercancel` gracefully to prevent stuck drag states.
  - Add 2-finger pinch-to-zoom calculation on touch devices.

### 4. Responsive & Touch Styling (`css/style.css`)
- **Touch Action Optimization**:
  - Add `touch-action: none; -webkit-touch-callout: none; user-select: none; -webkit-user-select: none;` on `#viewport-container`, `#circuit-svg`, and `.canvas-component` to ensure touch drag events aren't intercepted by mobile OS scroll/zoom gestures.
- **Mobile Header Decluttering**:
  - Hide all desktop action buttons in `.toolbar-actions` under `@media (max-width: 768px)`, leaving only the drawer toggles and centered branding.
- **Floating Action Button & Expanding Menu Styling**:
  - Design floating action button: `bottom: 1.25rem; right: 1.25rem`, circular gradient, subtle glowing border, animated icon toggle between 3-dots and close X.
  - Design expanding popup sheet: `position: fixed`, elevated card with frosted glass (`backdrop-filter: blur(16px)`), responsive action tiles with icons, hover/tap effects, and spring slide-up animation.
  - Position viewport controls (`bottom: 1.25rem; left: 1.25rem`) to ensure zero collision.
  - Hide `#mobile-fab-container` on desktop screens (`> 768px`).

### 5. Offline Service Worker & Documentation Sync
- **Service Worker (`sw.js`)**: Bump `CACHE_VERSION` to `'v0.1.10'`.
- **Changelog (`doc/versions.md`)**: Update version header to `[v0.1.0 to v0.1.10]` and document the Wokwi modal fix, mobile floating menu, and touch drag improvements.
- **Project Documentation (`doc/DOCUMENTATION.md`)**: Update version history and service worker cache reference.
- **Readme (`README.md`)**: Update version badge and mobile UI documentation.
