# Universal Eagle BRD Parser & Scalable Multi-MCU Engine

## User Review Required

> [!IMPORTANT]
> - Replacing the previous hardcoded keyword-based synthesizers with a **True Universal Ingestion Engine**:
>   1. **Autodesk EAGLE XML (`.brd`) Parser**: Reads `<elements>` and `<signals>` exported from Tinkercad to reconstruct any arbitrary circuit, any number of microcontrollers ($N \ge 1$), any parts, and exact electrical wiring.
>   2. **Dynamic Multi-MCU Architecture**: Handles 1, 2, 4, 8, 12+ Arduinos in `toWokwi`, `fromWokwi`, canvas layout, and inter-board wire routing without ID collisions or short-circuits.
>   3. **NeoPixel Strip & Ring Integration**: Full SVG graphics, pin resolvers, and canonical Wokwi compilation.
>   4. **Transparent Tinkercad Link Guidance**: Clear UI instructions on Autodesk CORS boundaries with 1-click drag-and-drop or file upload for `.brd` and `.json`.

## Proposed Changes

### 1. Universal Eagle `.brd` (XML) & Multi-MCU Parser

#### [MODIFY] [js/translator.js](file:///d:/GitHub/OSS/TCAD-WOKWI-Translator/js/translator.js)
- **Implement `Translator.fromEagleBrd(xmlStr)`**:
  - Uses browser `DOMParser` to parse Eagle XML `<eagle><drawing><board>`.
  - Extracts all `<element>` tags (name, library, package, value, x, y, rot).
  - Maps Eagle packages to catalog types (e.g. `ARDUINO_UNO`, `NEOPIXEL_STRIP`, `RESISTOR`, `LED`, `LCD1602`, `BREADBOARD`, `POTENTIOMETER`, `PUSHBUTTON`, `DIP_IC`, etc.).
  - Extracts all `<signal>` tags and `<contactref>` pairs to build the electrical netlist.
  - Normalizes PCB mil/mm coordinates to canvas pixel coordinates.
- **Support in `fetchAndTranslateTinkercad`**:
  - Detects if payload is XML / `.brd` and passes to `fromEagleBrd`.
  - If payload is JSON:
    - If `parts`: runs `fromWokwi`.
    - If `components`: runs `fromTinkercad`.
  - Decouples from hardcoded semantic keywords: URL fallback cleanly generates an extensible workspace while advising the user to import their `.brd` or `.json` for full fidelity.
- **Arbitrary Multi-MCU Compilation in `toWokwi`**:
  - Supports any count of microcontrollers ($N \ge 1$).
  - Supports inter-board wiring and multi-source netlist collapsing.
- **NeoPixel Pin Normalization**:
  - Add `wokwi-neopixel-strip` and `wokwi-neopixel-ring` pin resolvers (`DIN`, `DOUT`, `5V`, `GND`).
