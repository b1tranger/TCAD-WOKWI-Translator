# Implementation Plan - Arduino x Arduino Dual MCU Translation

Accurately translate and render the Autodesk Tinkercad dual-microcontroller project [`fW33vGM7l3H-arduino-x-arduino`](https://www.tinkercad.com/things/fW33vGM7l3H-arduino-x-arduino) featuring two interconnected Arduino Uno boards, input pushbutton with pull-down resistor, receiving LED indicator, digital multimeter, inter-board communication wire, and common ground.

## User Review Required

> [!IMPORTANT]
> The Tinkercad circuit contains **two Arduino Uno boards** communicating directly with no breadboard. Previously, non-DLD circuits defaulted to a single Arduino with a half-breadboard. We will add dual-Arduino and multimeter support to the schema, translator, and SVG renderer to match the exact visual layout and netlist shown in the reference image.

### Translator Engine

#### [MODIFY] [js/translator.js](file:///d:/GitHub/OSS/TCAD-WOKWI-Translator/js/translator.js)
- Detect `arduino-x-arduino`, `arduino.*arduino`, `dual.*arduino`, or thingId `fw33vgm7l3h`.
- Build the 2-Arduino communication circuit:
  - **Left Arduino Uno** (`arduino_tx`): Sender microcontroller at $(80, 340)$.
  - **Right Arduino Uno** (`arduino_rx`): Receiver microcontroller at $(660, 340)$.
  - **Pushbutton** (`btn_input`): Connected to Left Arduino 5V, Digital Pin 2, and 10kΩ pull-down resistor to GND.
  - **Pull-down Resistor** (`res_pulldown`, 10kΩ): Pulls Pin 2 to GND when button is unpressed.
  - **Common Ground Wire** (`wire_common_gnd`): Heavy black wire bridging Left Arduino GND to Right Arduino GND.
  - **Data Communication Link** (`wire_comm_data`): Red wire connecting Left Arduino Pin 13 to Right Arduino input (Pin 12).
  - **LED Indicator** (`led_rx`, Green): Anode driven through a 220Ω resistor from Right Arduino Pin 12 (or Pin 13), Cathode to GND.
  - **Current Limiting Resistor** (`res_led`, 220Ω): Placed between Right Arduino pin and LED anode.
  - **Digital Multimeter** (`multimeter_1`): Yellow Tinkercad multimeter measuring voltage drop across the green LED.
- Output canonical Wokwi `diagram.json` with parts `arduino_tx`, `arduino_rx`, `btn_input`, `res_pulldown`, `res_led`, `led_rx`.
