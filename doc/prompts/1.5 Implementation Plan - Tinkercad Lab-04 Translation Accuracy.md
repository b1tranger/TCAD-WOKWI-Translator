# Implementation Plan - Tinkercad Lab-04 Translation Accuracy

Accurately translate and render the Autodesk Tinkercad circuit [`7MUYP3PeLDa-lab-04-2`](https://www.tinkercad.com/things/7MUYP3PeLDa-lab-04-2?sharecode=sMLPwlwy-5wDRI4JlPvDa-lHnxv_QTmCEdVNR0IPIQA) into the Native Circuit Schema and Wokwi `diagram.json`, faithfully reproducing the circuit in the provided image.

## User Review Required

> [!IMPORTANT]
> The Tinkercad URL slug `7MUYP3PeLDa-lab-04-2` contains `lab-04`, which previously missed the logic filter regex (`/dld|logic|gate|assignment/i`) and erroneously fell back to an Arduino Uno default layout. We will implement dedicated recognition for Lab 04 / Boolean logic circuits (`74HC32` OR gate + `74HC04` NOT gate + DIP switch + DC power supply) matching the exact wiring shown in the attached image.

### Translator Pipeline

#### [MODIFY] [js/translator.js](file:///d:/GitHub/OSS/TCAD-WOKWI-Translator/js/translator.js)

  - Build the exact netlist with all 11+ connections visible in the user's image:
    1. DC Power supply (+) to Top `+` rail.
    2. DC Power supply (-) to Top `-` rail.
    3. Rail bridge: Top `+` to Bottom `+` rail (col 2).
    4. Rail bridge: Top `-` to Bottom `-` rail (col 30).
    5. DIP Switch 1 top terminal to Bottom `+` rail (col 4).
    6. DIP Switch 2 top terminal to Bottom `+` rail (col 5).
    7. DIP Switch 1 bottom terminal (Input B) to 74HC04 pin 1 (col 17).
    8. DIP Switch 2 bottom terminal (Input A) to 74HC32 pin 1 (col 6).
    9. 74HC32 pin 14 (VCC) to Top `+` rail (col 6).
    10. 74HC32 pin 7 (GND) to Bottom `-` rail (col 12).
    11. 74HC04 pin 14 (VCC) to Top `+` rail (col 17).
    12. 74HC04 pin 7 (GND) to Bottom `-` rail (col 23).
    13. 74HC04 pin 2 (Output 1Y, labeled $B'$) to 74HC32 pin 2 (col 7).
    14. 74HC32 pin 3 (Output 1Y, labeled $A + B'$) to LED Anode (col 28).
    15. LED Cathode (col 29) to Top `-` rail (col 29).
- Update `Translator.toWokwi` and `Translator.fromWokwi` to map these components cleanly to Wokwi `diagram.json`.
