# Standalone HTML Export & Wokwi diagram.json Loading Fix

## User Review Required

> [!IMPORTANT]
> - The root cause of the blank `circuit.html` viewer was identified in `js/app.js`: `btnExportHtml` queried `document.getElementById('circuit-svg')`, whereas the canvas SVG element ID is `circuit-canvas`. Because `circuit-svg` evaluated to `null`, `renderedSvg` was exported as an empty string `""`, leaving `<g id="viewport-group"></g>` empty.
> - `circuit.html` previously lacked an embedded runtime renderer and file open capability. If opened independently or if `diagram.json` needed to be previewed, it had no way to parse or render files locally.
> - We will fix the export selector, embed a self-contained renderer + file-loader in `circuit.html`, and add native File Picker + Canvas Drag-and-Drop for `diagram.json` and `circuit.json` across both the standalone viewer and the main app.

---

## Proposed Changes

### 1. Canvas Viewport Selector & Standalone HTML Export Fix

#### [MODIFY] [js/app.js](file:///d:/GitHub/OSS/TCAD-WOKWI-Translator/js/app.js)
- Fix `btnExportHtml` listener:
  - Query `this.renderer?.viewportGroup?.innerHTML || document.getElementById('circuit-canvas')?.querySelector('#viewport-group')?.innerHTML || ''`.
  - Add fallback: if `viewportGroup` is empty or missing, trigger `this.renderer.render(this.project)` before capturing the DOM.
- Add Toolbar File Open input and handler:
  - Add hidden file input `<input type="file" id="file-input-circuit" accept=".json">`.
  - Add "Open File" button to the header toolbar.
  - Add drag-and-drop listener on `#canvas-container` to accept dropped `.json` / `diagram.json` files and load them via `this.importTinkercadProject('', fileContent)`.
