# Implementation Plan: Universal Tinkercad Circuit Ingestion, Spatial Layout & Breadboard Snapping

Enable TCAD-WOKWI-Translator to import and translate **any arbitrary public circuit design** from Tinkercad (`https://www.tinkercad.com/things?type=circuits`), maintaining faithful spatial arrangements, proper component translations, and breadboard tie-point snapping.

## User Review Required

> [!IMPORTANT]
> - **Any Tinkercad Public Design**: Instead of relying on a handful of hardcoded project presets, the translation pipeline will feature a **Universal Semantic Ingestion & Synthesis Engine** that parses the title, URL slug, description, and keywords of *any* public Tinkercad circuit link (traffic lights, ultrasonic radars, servo sweepers, 555 timers, motor drivers, LDR night lights, logic gates, etc.).
> - **Universal JSON Normalizer**: `Translator.fromTinkercad(json)` will accept and normalize all arbitrary Tinkercad schema variants, Wokwi `diagram.json`, and native formats, mapping component aliases and scaling coordinates.
> - **Faithful Spatial Arrangement**: Layouts will preserve the arrangement of the original design (e.g. microcontroller on the left, breadboard in the center, and sensors/actuators oriented consistently), with automatic snapping of components into breadboard tie-points.

---

## Proposed Changes

### 1. Translation Engine (`js/translator.js`)

- **Universal Component Alias & Normalization Dictionary**:
  - Build a comprehensive catalog normalizer mapping hundreds of Tinkercad/EAGLE part names, aliases, and abbreviations (e.g., `Arduino Uno R3`, `atmega328p`, `74HC08`, `7408`, `pot`, `potentiometer_10k`, `servo`, `micro_servo`, `hc-sr04`, `ultrasonic`, `ldr`, `photoresistor`, `tmp36`, `pir`, `dc_motor`, `555_timer`, etc.) to canonical `COMPONENT_CATALOG` types.
- **Universal JSON Normalizer (`Translator.fromTinkercad`)**:
  - Normalize various component array structures (`components`, `parts`, `elements`, `devices`, `schematic`).
  - Normalize connection structures (`connections`, `wires`, `nets`, `signals`).
  - Normalize coordinate transformations: auto-scale and offset components to ensure proper canvas positioning while maintaining relative spatial distances.
  - Automatically detect and snap components located on or near breadboards onto tie-point columns/rows.
- **Universal Semantic Circuit Ingestion (`Translator.buildTinkercadTranslatedProject`)**:
  - Extract all semantic tokens from URL slugs, titles, and descriptions.
  - Classify circuit categories across the entire Tinkercad Circuits gallery:
    1. **Traffic Light Controllers** (Arduino + Red/Yellow/Green LEDs + Resistors)
    2. **Ultrasonic Distance / Radar / Parking Alarms** (Arduino + HC-SR04 + Buzzer/LEDs/LCD)
    3. **Light-Activated Switches & LDR Night Lights** (Arduino or 555/Transistor + Photoresistor + Resistor + LED)
    4. **Servo Motor Control & Sweepers** (Arduino + Servo + Potentiometer)
    5. **DC Motor Drivers & Fans** (Arduino + DC Motor + TIP120 + Diode + Potentiometer)
    6. **Temperature & Fire Alarms** (Arduino + TMP36 + LEDs + Buzzer + LCD)
    7. **PIR Motion Detector Systems** (Arduino + PIR Sensor + Buzzer + LED)
    8. **Digital Displays & Counters** (Arduino + 7-Segment / LCD1602 / OLED SSD1306)
    9. **RGB LED Color Mixers** (Arduino + RGB LED + 3x Pots/Buttons)
    10. **Buzzer Melodies & Mini Pianos** (Arduino + Pushbuttons + Piezo)
    11. **555 Timer Astable / Monostable Flashers** (NE555 + 9V + Capacitors + Resistors + LED)
    12. **Combinational Digital Logic Gates** (7400 NAND, 7404 NOT, 7408 AND, 7432 OR, 7486 XOR + DIP Switch + LEDs)
    13. **Battery Monitors & Voltage Testers** (9V / AA Battery + Voltage Divider + Multimeter)
    14. **Dual MCU Master-Slave Systems** (Dual Arduinos + I2C/Serial)
    15. **Generic Dynamic Synthesizer**: Extracts every recognized component from text, selects appropriate power and breadboard units, arranges them with MCU on left and breadboard in center, snaps components into breadboard holes, and routes power rails and signal lines.

### 2. User Interface & Sample Links (`index.html`, `js/ui.js`, `js/app.js`)

- Ensure error messages provide helpful guidance if a private link is pasted.
