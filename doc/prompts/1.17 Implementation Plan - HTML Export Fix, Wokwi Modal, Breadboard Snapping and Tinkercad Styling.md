# Implementation Plan: HTML Export Fix, Wokwi Export Modal, Breadboard Snapping & Tinkercad Styling

Implement **Release v0.1.9** addressing five core user requirements:
1. **Fix Standalone HTML Export**: Eliminate the blank canvas bug by generating self-contained SVG DOM elements and interactive pan/zoom controls directly inside the exported `.html` file.
2. **Wokwi Export Modal**: Replace direct file download with a dedicated modal containing copy-to-clipboard, file download, formatted JSON preview, and a direct link to the Wokwi simulator.
3. **Breadboard Snapping & Logical Connections**: Implement tie-point snapping during component drag and automatically synthesize logical electrical connections between component leads and breadboard columns/rails in the circuit model and Wokwi export.
4. **Tinkercad Component Styling**: Enhance component graphics to closely emulate Autodesk Tinkercad aesthetics (bone-white breadboard casing, metallic leads, translucent glass LEDs, ceramic resistors, matte ICs with silkscreen labels).
5. **Header GitHub Icon**: Add a GitHub repository icon button in the top navigation bar linking directly to the project's repository.

---

## User Review Required

> [!IMPORTANT]
> - **Breadboard Snapping Radius**: Snapping will automatically engage when a component's pin comes within 15px of a breadboard tie point.
> - **Logical Connection Generation**: When a component is placed on a breadboard, its pins will be mapped to the underlying breadboard column (`col 1..30` top/bottom strips or power rails). In Wokwi `diagram.json`, connections will explicitly link each component lead to the breadboard pin (e.g. `["bb1:14t.a", "r1:1", "green", []]`), enabling Wokwi's simulator to recognize the shared breadboard net.
